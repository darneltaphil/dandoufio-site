DANDOUFIO — Site du temple
==========================

Fichiers
  index.html         La page du site (ouvrez-la dans un navigateur).
  gallery.js         Index des albums, GENERE automatiquement — ne pas editer a la main.
  build-gallery.py   Script qui lit le dossier images/ et (re)genere gallery.js.
  images/            Vos albums de photos.
  assets/            Photos fixes de la page (carrousel, temple, Thron, contact).

Le carrousel et les photos fixes
--------------------------------
Les 7 photos du carrousel sont dans  assets/carousel/  (01.jpg ... 07.jpg).
Pour changer une photo : remplacez le fichier en gardant le meme nom.
Pour ajouter/retirer une photo ou changer sa legende : modifiez la liste
« slides » dans index.html (chercher  HERO carousel ) :
    {img:"assets/carousel/01.jpg",k:"Le gardien",t:"[Nom du Hounon]"},
Les autres photos fixes : assets/temple.jpg, assets/thron.jpg, assets/contact.jpg.

La galerie
----------
1. Dans le dossier  images/ , creez un sous-dossier par album, par ex :
       images/ceremonie-2024/
       images/funerailles/
       images/initiation/
   Le nom du dossier devient le titre de l'album
   (ceremonie-2024  ->  « Ceremonie 2024 »).

2. Deposez les photos (.jpg .png .webp) dans chaque dossier d'album.

3. Lancez le script une fois pour mettre a jour la galerie :
       python3 build-gallery.py
   (il recree gallery.js). Relancez-le a chaque ajout/retrait de photos.

4. La page montre 9 photos au hasard ; le bouton « Voir toute la galerie »
   ouvre tous les albums.

Mise en ligne
-------------
Mettez TOUT le dossier en ligne (index.html + gallery.js + images/ + assets/).
Les miniatures des 3 videos se chargent depuis YouTube (connexion requise).

Textes a completer : cherchez les crochets [ ... ] dans index.html
(nom du Hounon, adresse, numero WhatsApp, titres de videos, etc.).
